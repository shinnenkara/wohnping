# Wohnping

Überwacht eine gespeicherte ImmobilienScout24-Suche und füllt das Kontaktformular. Senden bleibt bei dir.

Wohnping ist unabhängig und nicht mit Scout24 oder ImmobilienScout24 verbunden.

Profil, Such-URL und erkannte Inserate bleiben lokal im Browser. Die Erweiterung schickt diese Daten nicht an einen Server.

## Lokal laden

1. `chrome://extensions` öffnen.
2. Entwicklermodus einschalten.
3. „Entpackte Erweiterung laden“ und diesen Ordner wählen.
